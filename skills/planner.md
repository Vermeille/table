---
name: table-planner
description: Build and refine weekly meal schedules from the Table cookbook and household preferences.
---
Use the table_cli.py beside this skill with terminal. Start with help and context. The current week is provided in the task; always pass week in context and writes. Read cookbook and persistent planner preferences. Write a complete schedule using save_week with its current version and slots (day 0=Monday through 6=Sunday, meal breakfast/lunch/dinner, recipe_id, servings). Use dinner by default unless asked otherwise. Keep unaffected slots when editing. Only cookbook recipes can be scheduled. Ask the cookbook assistant to add missing recipes rather than inventing IDs. Saving reopens the plan and invalidates shopping approvals. You cannot approve plans: tell the owner to use Approve week. Use learn to incorporate explicit reusable feedback into current learned guidance.

Rédige toutes les réponses et tout contenu destiné à l’utilisateur en français : recettes, ingrédients, étiquettes, listes et indications apprises. Conserve les noms techniques des actions, champs JSON et identifiants existants.

Quand `context.freezer.settings.enabled` est vrai, organise la semaine autour du **congélateur** et des jours où la personne peut cuisiner :
- Consulte `context.freezer.lots` et le budget `automatic_portions`. Programme quelques plats déjà congelés, en privilégiant les lots plus anciens, sur les jours chargés. Pour proposer un lot, utilise son `recipe.id` dans le créneau, même pour un plat qui existe uniquement au congélateur. Table fait les affectations et conserve une réserve. Ne force pas un lot précis ; l’interface permet au propriétaire de le réserver explicitement.
- Préfère un petit nombre de jours de cuisine réalistes. Une première occurrence d’une recette `freezer_ok: true` est cuisinée, puis Table peut congeler ses portions supplémentaires pour une occurrence sur un autre jour. Répète volontairement des plats compatibles à quelques jours d’intervalle, en alternant les plats. Garde les textures fragiles et les repas que la personne souhaite frais pour des créneaux adaptés.
- Quand le congélateur est vide, utilise quelques recettes compatibles pour constituer le stock progressivement. Quand il est fourni, utilise une partie des portions et répartis les cuissons plutôt que de tout vider ou de faire une énorme séance. La capacité maximale par jour concerne les portions supplémentaires.
- Préserve le contenu des créneaux déjà enregistrés dans `recorded_actions` (sauf les repas annulés). Après `save_week`, lis les affectations réelles dans `batch`. Résume quels jours cuisiner, les quantités à congeler et les repas à ressortir. Si un plat destiné à un jour sans cuisine se retrouve à cuisiner, ajuste la proposition en respectant les préférences. Table n’ajoute le stock qu’une fois la congélation confirmée par le propriétaire.
